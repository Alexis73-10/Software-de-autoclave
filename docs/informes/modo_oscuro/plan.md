# Modo oscuro: inventario y plan (paso 1)

Rama `modo-oscuro` (desde `dev` c43b9d0b). Fuente de valores: `docs/diseno/mockups/modo_oscuro/paleta_modo_oscuro.md`. Prompt: `docs/mis_plans/prompt_claude_code_modo_oscuro.md`. Este paso no toca código de producción.

## 1. Mecanismo de tema recomendado

- **Valores:** `Tema/Colores.qml` sigue siendo el único lugar con colores. Se agrega `property bool oscuro: false` (escribible, no `readonly`) y cada propiedad pasa a `readonly property color x: oscuro ? "#OSCURO" : "#CLARO"`. Así Colores no depende de ningún módulo Python: las 29 pruebas con QML en línea que hacen `import Tema` y las que cargan componentes sueltos siguen cargando y quedan en claro sin cambios.
- **Estado:** singleton Python nuevo `Autoclave.Apariencia` (`ui_qml/bridge/apariencia_qml.py`, mismo patrón que `bridge/i18n_qml.py` y `unidades_qml.py`): propiedad `oscuro` (bool) / `tema` ("claro"|"oscuro") con señal `temaChanged`, sondeo de `GET /theme` cada 3 s para que la segunda pantalla siga a la primera (como I4 del idioma); respuesta ausente o inválida = conserva el vigente; valor inicial = claro. Registro al importar el módulo desde `ui_qml/app.py` (junto a `i18n_qml`).
- **Enlace:** cada raíz de ventana (`Main.qml`, `InstalacionVentana.qml`, `ReposoInstalacionVentana.qml`, `NuevoUsuarioHost.qml`) declara `Binding { target: Colores; property: "oscuro"; value: Apariencia.oscuro }`. Ninguna pantalla pregunta por el tema.
- **Persistencia (igual que el idioma):** el idioma vive en el backend: `core/runtime/config_idioma.py` → `data/idioma.json`, `GET/PUT /language` en `backend/rutas/sistema.py:828-845`, slot `ParametrosEquipoController.fijarIdioma` (`ui_qml/controllers/parametros_equipo_controller.py:268`) y selector `Selector { tipo: "idioma" }` en `Pantallas/OpcionesParametrosEquipo.qml:574` (confirmación por diálogo, `aplicarCambio()` l. 463). El tema va al lado: `core/runtime/config_tema.py` → `data/tema.json` (inválido o ausente = claro), `GET /theme` (sin rol) y `PUT /theme` **sin `_auditar`**, slot `fijarTema` con cambio local inmediato (como `fijarIdioma`) y `Selector { tipo: "tema" }` en la misma columna «máquina». Ver OSC-02.
- **Íconos:** monocromos con `IconoColor` (máscara, color exacto) en lugar de `Image`; nunca SVG duplicados salvo OSC-07.
- **Fondos:** `FondoApp.qml` en oscuro dibuja el gradiente radial §1 (Shape + `RadialGradient`) en vez de `fondo-arranque.png`; Reposo e IntroArranque igual (ver §2 d).
