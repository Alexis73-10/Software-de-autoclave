Chapter 1 Product Overview


1.1 Product Introduction

      This high-performance distributed I/O host supports standard
Modbus TCP and RTU protocols, making it suitable for data
acquisition and control. The device is equipped with dual 10/100M
adaptive Ethernet interfaces and supports switch functionality. The
internal bus speed can reach up to 1ms. It features a reset function
for both digital and analog outputs in case of network interruption,
ensuring restoration to a preset state in the event of communication
failure.
      The device features a modular design, allowing users to
flexibly expand it according to their actual needs. It supports
multiple I/O types, and when the existing configuration is
insufficient to meet specific application requirements, users can
easily add matching I/O expansion modules without replacing the
entire system, effectively saving costs and simplifying the on-site
deployment process.
      This product allows connection to up to 16 IO expansion
modules (including the host itself) and is built in accordance with EMC Level 3 protection standards. IO input/output
and power supply are fully isolated, providing excellent electromagnetic compatibility, outstanding performance and
high reliability, and meets CE certification standards.


1.2 Features

     Supports standard Modbus RTU protocol and Modbus TCP protocol;
     Supports various configuration software/PLC/touch screens;
     RS485 data acquisition and control I/O;

2.2Device connection

2.2.1 RS485 connection




     Note: When transmitting high-frequency signals on the 485 bus, the signal wavelength is relatively short
compared to the transmission line. The signal will be reflected at the transmission line terminal, interfering with the
original signal. Therefore, a terminating resistor needs to be added to the end of the transmission line to prevent
signal reflection. The terminating resistor should have the same impedance as the communication cable, typically
120 ohms. Its function is to match the bus impedance, improving the anti-interference capability and reliability of
data communication.

4.5.2 AI input integer values, floating-point values, and process quantities

      There are three ways to read the analog signals acquired by the device:
     （1） Read the AI engineering quantity integer value and directly convert it to the input current or voltage. The
AI engineering quantity integer value register starts at address 0x0000, is an input register, and has a read function
code of 0x04. This method returns a value where one register represents one channel.
Single-ended current: The value read is 0 to 20000. The method for calculating the current is that 0 to 20000
corresponds to 0mA to 20mA.
That is: Current = Project quantity value / 1000 (mA)

Differential current: The reading ranges from -20000 to 20000. The current magnitude is calculated as -20000 to
20000 corresponds to -20mA to 20mA.
That is: Current = Project quantity value / 1000 (mA)

Single-ended voltage : The value read is 0 to 10000. The method for calculating the voltage magnitude is that 0 to
10000 corresponds to 0 V to 10 V.
That is: Voltage = Engineering quantity value / 1000 ( V )

Differential voltage : The reading is -100000 to 10000. The voltage magnitude is calculated as -10000 to 10000
corresponds to -10V to 10V .
That is: Voltage = Engineering quantity value / 1000 ( V )

current type engineering quantity and process quantity is: Engineering quantity = Process quantity × 25000 / 32768.
The engineering quantity will be limited by the set engineering quantity range.
voltage type engineering quantity and process quantity is: Engineering quantity = Process quantity × 12000 / 32768.
The engineering quantity will be limited by the set engineering quantity range.
     （2） Read the floating-point value of the AI engineering quantity, and use the IEE754 converter to convert the
hexadecimal data to a floating-point number to obtain the input current or voltage. The starting address of the AI
engineering quantity integer value register is 0x03E8, the register type is an input register, and the read function code
is 0x04. This method returns two registers representing one channel.
     （3） Read AI process quantities. The AI process quantity register starts at address 0x0BB8, is an input register,
and has a read function code of 0x04. This method returns one register representing one channel. The process quantity
acquisition range converts current signals from -25 mA to 25 mA into digital values of -32768 to 32767. The
parameter range of the process quantity will vary depending on the set process quantity range.
     When the quantity range is set to a positive range (i.e., 0 ~ 20mA, 4 ~ 20mA), the parameter range of the process

4.5.3 AI filter parameters

The filtering parameters for the AI channel can be set, with valid values ranging from 0 to 4 and a default value of 0 .

4.7        PT100 input

4.7.1 Integer and floating-point values of quantities input into PT100

      There are two ways to read the PT100 temperature signal collected by the device:
     （1） Read the PT100 engineering integer value and directly convert it to the actual temperature. The PT100
engineering integer value register starts at address 0x0DAC, is an input register, and has a read function code of 0x04.
This method returns a value where one register represents one channel.

Temperature acquisition range: The read values are -2000 to 8500. The method for calculating the actual temperature
is -2000 to 8500, which corresponds to -200℃ to 850℃.
That is: Actual temperature = Project quantity value / 10 (°C)


    （2） Read the PT100 engineering floating-point value, and use the IEEE754 converter to convert the
hexadecimal data to a floating-point number to obtain the actual temperature. The PT100 engineering floating-point
value register starts at address 0x0EAC, is an input register, and has a read function code of 0x04. This method returns
two registers representing one channel.

     [Status Diagnostic Value Explanation] When the register reads the following special values, it represents the
status of the corresponding channel, not the actual temperature:
     32766: Sensor not connected or wired out (wired out when temperature exceeds 870℃)
     -32766: Short circuit condition (when the temperature is below -220℃, it is determined to be a short circuit
condition).
     32765: Chip fault (indicates that the ADC acquisition unit to which this channel belongs is malfunctioning and
cannot complete the temperature signal conversion).
     32767: Temperature overflow (triggered when the temperature exceeds 850°C but does not reach 870°C)
     -32768: Temperature overflow (triggered when the temperature is below -200°C but not below -220°C)
     -32767: Channel is disabled

4.11 Firmware Upgrade Tutorial

(1) In the upper right corner of the host computer, click the Menu and select upgrade tool.




(2) In the dialog box that appears, choose the firmware you wish to upgrade (the firmware is available for

      download on the official website)




(3) After adding the firmware, search for the device (here you must first select the network card; if unsure, please

      refer to the "Host Computer" section). Once the device appears, click "Stop Searching" to finish.




(4) When you open the drop-down box, you will see that the host contains an expansion module. When

      upgrading, select the model listed above to perform the upgrade. The expansion module generally does not

      need to be upgraded.

Chapter 6 Precautions

(1) Do not connect the equipment while it is powered on, otherwise there is a risk of damage to the equipment.
(2) The M31-U series host can only be used with U series expansion modules .
(3) Firmware version compatibility requirements between host and expansion modules
     1. Compatibility principle: The firmware version number of the host device must be greater than or equal to
the firmware version number of the expansion module it is paired with; otherwise, the device will not function
properly.
     2. Version compatibility example:
                      Host firmware version                            Compatible expansion module firmware version
                                 9232-0-10                                              9206-0-10, 9233-0-11
                                 9232-0-11                                       9206-0-10, 9233-0-11, 9233-0-12
                                 9232-0-12                                  9206-0-10, 9233-0-11, 9233-0-12, 9286-0-10
                                 9232-0-13                             9206-0-10, 9233-0-11, 9233-0-12, 9286-0-10, 9304-0-10


     3. Troubleshooting: If incompatible firmware versions are used in combination, the entire device will fail to
boot and operate. The host firmware must be upgraded to a version that meets compatibility requirements before
normal use.
